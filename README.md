# IML2025

This project addresses a machine learning task for voice-based access control, formulated as a binary classification problem in which audio recordings are transformed into spectrogram representations that serve as inputs to a neural network for authorization classification. The work covers the full ML pipeline, including compiling and preprocessing a dataset, applying augmentation, generating spectrogram features, and systematically experimenting with CNN design choices such as depth and filter sizes, batch normalization, dropout, different optimizers (SGD vs. Adam), learning rate scheduling, and regularization, ultimately leading to the selection of a ResNet-18–based model as the best-performing solution. 

Link to the dataset: https://www.kaggle.com/datasets/paulamatuszewska/spectrograms-aug/data
